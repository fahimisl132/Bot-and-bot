# Telegram Sales Bot

A Telegram Sales Bot built with Python and Aiogram 3.x.

## Features

- Customer Main Menu
- User Profile
- Product Management
- Nested Product Categories
- Add / Edit / Remove Products
- Set Product Prices
- Hide / Show Products
- Admin Panel
- SQLite Database

## Requirements

- Python 3.10+
- Telegram Bot Token
- Telegram User ID

## Installation

Install dependencies:

pip install -r requirements.txt

## Environment Variables

Configure these variables in Railway:

BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
OWNER_ID=YOUR_TELEGRAM_USER_ID

## Run Locally

python shop_bot.py

## Railway Deployment

1. Upload the project to GitHub.
2. Connect the GitHub repository to Railway.
3. Add BOT_TOKEN in Railway Variables.
4. Add OWNER_ID in Railway Variables.
5. Deploy the project.
